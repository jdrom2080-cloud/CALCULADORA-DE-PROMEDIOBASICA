# CALCULADORA-DE-PROMEDIOBASICA
Calculadora de promedios en materias de 3 parciales o 4 parciales, permitiendo conocer si es posible clasificar al exámen final de una materia con estas caracteristicas, mi primer proyecto

 # Como funciona?
  Solo rellena los campos con tus notas, y deja que la calculadora haga lo suyo, la condicion que debe de tener es que todos los parciales deben valer el 70% de la materia
